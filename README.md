# Manual Web Testing — SauceDemo

## Project Overview

This project demonstrates practical manual software testing skills using SauceDemo, a demo e-commerce web application.

**Application under test:** https://www.saucedemo.com/

The objective was to validate key user workflows, identify potential defects, and document test execution results.

## Tools & Techniques

- Manual Functional Testing
- Positive and Negative Testing
- Equivalence Partitioning
- Boundary Value Analysis
- Test Case Design
- Git & GitHub
- Microsoft Excel

## Test Coverage

The project includes 12 manual test cases covering:

- Successful user login
- Invalid login credentials
- Required field validation
- Adding products to the shopping cart
- Adding multiple products
- Removing products from the cart
- Product price sorting
- Successful checkout
- Checkout form validation
- Order total and tax calculation
